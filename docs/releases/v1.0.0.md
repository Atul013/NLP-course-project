Phish Lens is now available at **https://phish-lens-topaz.vercel.app**.

This first release brings the NLP coursework and phishing-detection project together under **NLP Course Project**.

### Included

- Responsive Phish Lens web app with message analysis, uncalibrated phishing probability, influential terms, processed tokens, examples, and keyboard controls.
- The existing NLTK + TF-IDF + logistic-regression classifier, training notebook, model comparison, metrics, split identifiers, and original Streamlit interface.
- A compact Vercel inference runtime using the saved model's fitted weights without retraining, with unchanged preprocessing and checksum-verified corpora.
- Updated course report, original text-preprocessing assignment, setup instructions, screenshots, and deployment documentation.

### Verification

- 13 API/runtime tests pass.
- Probabilities and term contributions match the original pipeline to 12 decimal places across 20 varied inputs.
- Live browser checks pass for real phishing/benign inference, token inspection, keyboard controls, safe rendering, reset, API errors, cancellation, and responsive layouts down to 320 px.
- The production page and model readiness endpoint return HTTP 200.

### Downloads

`NLP-course-project-v1.0.0.zip` contains project source plus exported runtime weights and verified NLTK corpora. It excludes local environments, credentials, caches, and raw dataset downloads. The PDF report, editable Markdown report, original assignment report, saved model, and evaluation metrics are also available individually. `SHA256SUMS.txt` verifies the attached files. GitHub's automatic source archives contain the committed source; follow `web/README.md` to export weights and prepare corpora when using those archives.

The classifier remains an educational prototype trained on a small synthetic dataset. Its recorded 1.00 test F1 on 40 synthetic messages does not establish real-world reliability. Probabilities are uncalibrated. Do not use predictions as permission to open links or attachments.
